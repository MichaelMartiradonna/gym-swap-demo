# Gym Swap — public portfolio demo

A public, read-only, fully static snapshot of the Gym Swap frontend: the real app, the complete reviewed library (133 exercises, 270 reviewed comparisons), a preloaded synthetic sample workout, equipment-note entry and occurrence-specific swap selection with Undo. No sign-in, no server, no database, no AI backend. "Ask about this swap" returns the written fallback, exactly as in the owner's private Lab.

Demo URL: [https://gymswap.seeform.ai](https://gymswap.seeform.ai) (hosted on Cloudflare Pages from this repository's `dist/`). Pages: `/` standard app, `/pilot/` opt-in six-row pilot, `/about/` scope and disclaimer.

Production (owner-private 2.8.1) and the private Gym Swap Lab are unaffected. This checkout reads the Lab's built output and never writes to it.

## How it was produced

`scripts/build.mjs` treats the Lab's built frontend (`../gym-swap-lab/dist/client`) as the source snapshot:

1. Copies every public file, excluding anything private (`.openai/`, `server/`, `lab-build.json`, `.env*`, `db/`, `*.sqlite*`, `evaluation/`, `.runtime/`, `.git/`).
2. Verifies every copied module and asset against the Lab's frozen `snapshot/manifest.json` SHA-256 digests. The two Lab-decorated HTML pages are un-wrapped first and verified the same way, so the demo provably derives from the reviewed snapshot. All 49 frozen files match; the app modules are byte-identical.
3. Re-wraps `/`, `/pilot/` and `/about/` with the demo banner ("Portfolio demo · reviewed library · AI explanations disabled") and `demo.css` (the Lab stylesheet with its selector renamed), adds one public-demo line to About, and inserts two small inline scripts into the app pages before the app module:
   - an `/api/` fetch shim that answers in-page with the same `{status:'unavailable', answer, citations:[]}` JSON (HTTP 503) the Lab Worker returns, so no request leaves the browser;
   - a first-visit seed that stores one synthetic six-line "Sample workout" under the frontend's own versioned key `gym-swap.workouts.v1`, only when neither that key nor the legacy `gym-swap.active-workout.v1` key exists. The record is generated by the snapshot's own parser/validator, so its schema and catalogue signatures are exact.
4. Adds static-host helpers: `_redirects` and `_headers` (Cloudflare Pages), a meta-refresh `prototype/index.html` and `.nojekyll` (GitHub Pages), and `404.html`.
5. Writes `dist/demo-build.json` with the source fingerprint and a fingerprint of the public output.

Source snapshot recorded in `dist/demo-build.json`:

- Lab snapshot id `84beb762a173d64d9d4c8d19174d7c1f2a6b3e7df185c36775b87495b6bf95f7`
- Reviewed source revision `11e4acedad8ab082c18ab74b54b5253a4d1a6ed62578ac3d21f9db2b15a1e9ff` (label "Workout library", source build 2.8.1, Lab v5 / M4 follow-up)
- `modelCalls: disabled`

When the Lab checkout is not present (for example in hosting CI), `npm run build` does not rebuild; it verifies the committed `dist/` against the fingerprint in `demo-build.json` and exits successfully.

## Build, test, preview

Node 22+. No dependencies to install.

```sh
npm run build     # rebuilds dist/ from ../gym-swap-lab (or verifies dist/ when the Lab is absent)
npm test          # node --test tests/*.test.mjs
npm run preview   # static preview at http://127.0.0.1:50813/ (node scripts/preview.mjs [port])
```

The preview behaves like a static host: directory index pages, the `_redirects` rules, `404.html`, no API routes (a `/api/` request is a 404/405 at the host; the page answers it in-page as unavailable).

Set `GYM_SWAP_LAB=/path/to/gym-swap-lab` if the Lab checkout is not beside this folder.

## Tests

`tests/demo.test.mjs` ports the Lab's hosting regressions where a static host makes them meaningful and adds the demo-specific guarantees:

- snapshot fingerprint recorded and public output fingerprint reproducible;
- every frozen module/asset byte-identical to the Lab manifest (skipped automatically when the Lab checkout is absent);
- standard/pilot pages: demo banner, pilot marker only on `/pilot/`, no Lab identity or production link;
- About content and footer preserved, one public-demo line with the GitHub link;
- old bookmarks resolve (`_redirects`, meta-refresh page);
- `/api/` answered in-page as `unavailable` with empty citations; the untouched `explanation.mjs` degrades to its written fallback on a thrown fetch or an HTML 404;
- `test_demo_has_no_private_files`;
- `test_demo_preloads_sample_workout` (seed script present before the app module, references the real storage key, seeds only when the key is absent, record validates with the snapshot's own validator, all six lines have reviewed swaps);
- no Lab/production hostnames, Site identities or personal workout text anywhere in `dist/`;
- the preview server's static-host behaviour.

## Sample workout

Six synthetic lines, no real person: goblet squat, dumbbell RDL, seated cable row, machine chest press, barbell split squat (bar on upper back, both feet on the floor), single-leg floor bridge. Each matches the catalogue exactly and has reviewed swaps (13 / 9 / 3 / 9 / 5 / 6). It is seeded once per browser origin; **New workout** starts a fresh workout and the sample then sits in **My workouts** until you delete it. Everything stays in the visitor's browser.

## Deploy

Commit `dist/` (the build needs the private Lab, which hosting CI does not have).

**Cloudflare Pages** (preferred): create a Pages project from the repository; build command `npm run build`, build output directory `dist`, Node version 22. `_redirects` and `_headers` are picked up automatically.

**GitHub Pages**: publish `dist` — either enable Pages with the included `.github/workflows/pages.yml` (builds in verify-only mode, runs the tests, uploads `dist`), or point Pages at a branch whose root is the contents of `dist`. `.nojekyll` is included so `_redirects`/`_headers` are served harmlessly.

After deploying, put the URL in this README and in `README_TOP.md`, then open `/`, `/pilot/`, `/about/` and check that the banner reads "Portfolio demo · reviewed library · AI explanations disabled".
